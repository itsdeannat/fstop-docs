The Fstop API includes an endpoint that allows client applications to create new bookings in the database.

In this guide, you'll make a `POST` request to the `/api/bookings/` endpoint to create a new booking for a project.

## Before you begin

Before you make a `POST` request, ensure that you have an access token. For instructions on requesting an access token, see [Getting started with the Fstop API](./getting-started).

You'll also need the UUID of an existing project to associate with the booking.
